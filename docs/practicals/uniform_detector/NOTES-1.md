## Session plan (about 50 minutes, CPU only)

- Before the setup: the notebook tells students to download the ten data files from the page and drag them into the Files panel (the site does not serve them until the folder is pushed). The setup cell still tries the download from the page for any missing file, then checks that all ten are present.
- Setup, about 1 minute (pip install of ultralytics with the constraints pattern), then a hidden helper cell.
- Part 0 lives on the page only (0.1 image as three arrays, 0.2 kernels, 0.3 ReLU and pooling, 0.4 flatten and linear, 0.5 training vocabulary). The notebook points to it and does not repeat it. The four Part 0 figures on the page were generated by the old notebook cells, so the PNGs in `assets/` are now the only copies.
- Part 1 (about 4 minutes): load the crops, balanced counts, grid; the demo colour rule scores 0.68 on the test set (misses 33 of 52 workers).
- Part 2 (about 6 minutes): tensors; the training loop in visible code (`train_model`, `run_experiment`); 2.3 glosses each layer of the first model in one line (Conv2d, ReLU, MaxPool2d, Flatten, Linear) with a pointer to Part 0 of the page; the first model (1 conv with 4 kernels, pool 8, linear; 369 parameters; 5 epochs at lr 0.001) scores about 0.72.
- Part 3 (30 minutes): the challenge. Target: test accuracy ≥ 0.95, < 50,000 parameters, ≤ 60 s training; fewest parameters wins. Students edit the architecture and the training arguments directly in code. Every run adds a row to an experiment log (pandas table) with a "target reached" column. Then a cell picks the best run, prints the confusion matrix and the mistakes.
- Part 4 (about 5 minutes): YOLOv8 on two scenes (4.1), on `workshop_walk.mp4` (4.2) and on the other two videos (4.3) with the best model; green = authorised, red = not; the rule's answer as a tag. `annotate_video(name)` writes `<name>_annotated.mp4` and shows six full frames. 4.3 asks which video gives the model the most trouble and sends students back to Part 3 if the second camera fails.
- Discussion (5 questions), Advanced 1 (kernels and feature maps of the first layer), Advanced 2 (1 × 1 kernels = learned colour rule, about 0.91), Advanced 3 (40 training crops, overfitting), troubleshooting with the two shape errors students will meet.

## Results observed (CPU, seed 0)

| run | model | epochs | lr | params | seconds | test acc |
|---|---|---|---|---|---|---|
| first model | 1 conv (4 kernels), pool 8 | 5 | 0.001 | 369 | 0.5–1.7 | 0.72 |
| more epochs | same | 15 | 0.001 | 369 | 1.3 | 0.81 |
| larger lr | same | 15 | 0.01 | 369 | 1.3 | 0.99 (seed 1: 0.99) |
| two conv blocks | 8 + 16 kernels | 15 | 0.001 | 2,417 | 2.7 | 0.97 (seed 1: 0.76) |
| two conv blocks | same | 15 | 0.01 | 2,417 | 2.9 | 0.98 |
| two conv blocks | same | 15 | 0.1 | 2,417 | 2.5 | 0.50 (stuck) |
| 1 × 1 kernels | Advanced 2 | 15 | 0.01 | 273 | 1.5 | 0.91 |

The task is easy for a CNN, so the challenge is about calibration and about reaching the target with few parameters. The smallest solution found has 369 parameters.
